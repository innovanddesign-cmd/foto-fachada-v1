Prevención de regresiones

Se ha preparado un flujo de GitHub que ejecuta instalación limpia, auditoría, pruebas, revisión estática y compilación. Entrará en funcionamiento cuando se publique la rama; no se ha ejecutado remotamente todavía. No se han añadido exclusiones al informe de seguridad ni se han ocultado avisos.

Comprobación y límites

Las once suites locales pasan. La compilación y la revisión de tipos se comprueban tras los cambios. Las advertencias no bloqueantes de imágenes o dependencias de efectos de React son distintas de los avisos de seguridad corregidos. No se ha desplegado esta versión ni se han alterado datos de clientes.

La actualización de estilos sigue la guía oficial de Tailwind. El editor requiere navegadores actuales compatibles con Tailwind 4: Safari 16.4+, Chrome 111+ y Firefox 128+. Las páginas públicas generadas emplean su propio CSS.
