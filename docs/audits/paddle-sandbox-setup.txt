CONFIGURACIÓN PENDIENTE EN LA CUENTA PADDLE SANDBOX
- API key de servidor, permisos price.read, transaction.read y transaction.write.
- Client-side token test_. No es la API key del servidor.
- Notification destination: https://foto-fachada-v1.vercel.app/api/paddle/webhook
- Suscribir transaction.completed. Guardar el secreto de firma solo en Vercel.
- Default payment link: https://foto-fachada-v1.vercel.app/checkout/paddle
- Siete precios EUR con tax_mode=external, cantidad 1:
  PRO monthly 2000 céntimos / mes; PRO annual 10000 / año.
  BUSINESS monthly 3800 / mes; BUSINESS annual 19000 / año.
  CREDITS small 500; medium 1200; large 2500, sin recurrencia.
- Variables exactas en .env.example. No pegar secretos en chats, documentos o Git.

PRUEBA CONECTADA PENDIENTE
Login -> producto -> crear transacción servidor -> checkout Paddle -> tarjeta Sandbox -> transaction.completed firmado -> historial confirmado.
Probar rechazo, repetición del webhook, reintento de petición, retraso de notificación y volver a abrir la página.
